# 动作图解素材目录

后续把动作图解图片放在这个目录，并在 `utils/exerciseLibrary.js` 里把对应动作的 `imageUrl` 改成图片路径。

建议先补充这些核心动作：

- `barbell-bench-press.png`：杠铃卧推
- `lat-pulldown.png`：高位下拉
- `squat.png`：深蹲
- `leg-press.png`：腿举
- `dumbbell-shoulder-press.png`：哑铃推举
- `lateral-raise.png`：侧平举
- `plank.png`：平板支撑

示例：

```js
杠铃卧推: {
  imageUrl: '/assets/exercises/barbell-bench-press.png',
  videoUrl: ''
}
```

正式上线建议使用自己拍摄、购买授权或明确可商用的素材。
