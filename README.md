# Fit Note

当前版本：`v0.8.0`

面向健身房新手和入门用户的微信小程序，支持按增肌/减脂目标生成训练计划、执行今日训练、查看动作库、学习动作要点、查看动作图解占位、逐组记录训练、记录饮食，并通过首页查看今日任务和完成情况。

## v0.8.0 已实现功能

- 首页：今日训练仪表盘、欢迎语、今日训练进度、今日完成度、本周训练数据、饮食状态、动作库快捷入口
- 计划页：增肌计划、减脂计划、生成计划、我自有计划、动作部位选择、动作建议自动匹配
- 今日训练页：读取当前目标的今日计划，展示动作列表、完成进度、动作记录状态，并支持查看动作详情
- 训练页：每组单独记录重量和次数，支持添加一组、删除一组、复制上一组、复制上次同动作训练记录
- 饮食页：根据体重和目标估算热量目标、蛋白质目标和饮水目标，支持快捷饮水
- 动作库页：按胸部、背部、腿臀、肩部、手臂、核心、有氧分类查看动作，支持搜索
- 动作详情页：展示动作介绍、训练目标、动作步骤、训练要点、常见错误和新手建议
- 我的页：设置基础资料，并提供关于我们、隐私说明、用户协议、数据说明入口
- 云开发：已在 `app.js` 初始化 CloudBase 环境，已配置 `cloudfunctions/` 云函数目录

- 在 `app.js` 中接入 `wx.cloud.init`
- 将 CloudBase 环境 ID 写入全局配置
- 在 `project.config.json` 中配置 `cloudfunctionRoot: "cloudfunctions/"`

## 数据保存

当前版本仍使用微信小程序本地缓存，不需要登录和后端即可运行。

注意：如果用户清理微信缓存、删除小程序缓存或更换设备，数据可能丢失。后续正式版建议继续接入云数据库和云函数，实现登录、多设备同步和数据备份导出。

## 如何运行

1. 安装微信开发者工具。
2. 打开微信开发者工具，选择“导入项目”。
3. 项目目录选择当前文件夹。
4. 当前 `project.config.json` 已配置测试号 AppID，如需发布请换成正式小程序 AppID。
5. 点击“编译”预览。
