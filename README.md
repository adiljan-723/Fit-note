# Fit Note

当前版本：`v0.9.1`

面向健身房新手和入门用户的微信小程序，支持按增肌/减脂目标生成训练计划、执行今日训练、查看动作库、学习动作要点、查看动作图解占位、逐组记录训练、记录饮食，并通过首页查看今日任务和完成情况。

## v0.9.1 已实现功能

- 首页：今日训练仪表盘、欢迎语、今日训练进度、今日完成度、本周训练数据、饮食状态、动作库快捷入口
- 计划页：增肌计划、减脂计划、生成计划、我自有计划、动作部位选择、动作建议自动匹配
- 今日训练页：读取当前目标的今日计划，展示动作列表、完成进度、动作记录状态，并支持查看动作详情
- 训练页：每组单独记录重量和次数，支持添加一组、删除一组、复制上一组、复制上次同动作训练记录
- 饮食页：根据体重和目标估算热量目标、蛋白质目标和饮水目标，支持快捷饮水
- 动作库页：按胸部、背部、腿臀、肩部、手臂、核心、有氧分类查看动作，支持搜索
- 动作详情页：展示动作介绍、训练目标、动作步骤、训练要点、常见错误和新手建议
- 我的页：设置基础资料，展示本地数据保存说明，并提供关于我们、隐私说明、用户协议、数据说明入口
- 数据保存：当前版本采用微信小程序本地缓存，不依赖付费云开发，不会主动发起云同步请求
- 后端规划：保留 `cloudfunctions/` 目录和后端升级思路，后续可按需接入 CloudBase 或自建后端

## 当前版本定位

`v0.9.1` 是本地稳定版，适合继续开发、面试展示和 GitHub 版本管理。

当前版本采用本地缓存完成 MVP 验证，重点验证以下核心流程：

```text
训练计划 → 今日训练 → 训练记录 → 饮食记录 → 动作学习 → 首页反馈
```

暂不启用云开发，避免未开通云环境时出现云同步失败。

## 数据保存

当前版本数据保存在微信小程序本地缓存中：

```text
fitnote_profile           用户资料
fitnote_training_records  训练记录
fitnote_diet_records      饮食记录
fitnote_workout_plan      训练计划
fitnote_checkins          今日打卡
fitnote_training_draft    训练草稿
```

注意：如果用户清理微信缓存、删除小程序缓存或更换设备，本地记录可能丢失。

## 后端升级规划

后续如果需要多设备同步、数据备份或真实上线，可继续升级为云端版：

```text
users              用户身份
user_profiles      用户资料
training_records   训练记录
diet_records       饮食记录
workout_plans      训练计划
checkins           打卡记录
```

可选后端路线：

- CloudBase：适合微信小程序快速接入云函数、云数据库和文件存储
- 自建后端：适合练习完整后端接口、数据库、部署和运维能力
